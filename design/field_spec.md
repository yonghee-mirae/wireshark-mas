# Code Fields

- 149 전일대비구분
- 742 정규장 전일대비구분
- 752 주간거래 정규장 대비구분

위 필드들의 값은 각각 다음과 같은 의미를 가짐

- 1: 상한
- 2: 상승
- 3: 보합
- 4: 하한
- 5: 하락

이 필드들은 상세창에 다음과 같은 형태로 출력

```
field_name: 1 (상한)
```

# Code & Value Fields

- 024 전일대비
- 743 정규장 전일대비
- 753 주간거래 정규장 대비

위 필드들의 값은 코드+값의 형태로 구성됨

예) 2500 = 상승 500, 5250 = 하락 250

이 필드들은 상세창에 다음과 같은 형태로 출력

```
field_name: 500 (2;상승)
```
